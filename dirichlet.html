How to use the Dirichlet distribution explorer

Choose the number of slots and a total amount, then select a symmetric or asymmetric alpha configuration. The tool samples gamma-distributed values, normalizes them into proportions, and scales those proportions to your target total.

What does the alpha parameter control?

Alpha values control the shape of the distribution. With symmetric alpha values below one, samples tend to be more uneven. Values above one generally produce allocations closer to equal shares. In asymmetric configurations, larger alpha values correspond to larger expected proportions.

Symmetric vs. asymmetric Dirichlet distributions

A symmetric Dirichlet distribution uses the same alpha parameter for every component. An asymmetric distribution assigns a different alpha parameter to each component, allowing different expected shares.
